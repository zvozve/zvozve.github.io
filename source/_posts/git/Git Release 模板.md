## Gitea Release 各字段填写指南

### 1. 标签名称 (Tag name)

**必填**，用于标识版本号，遵循语义化版本规范。

```bash
# 格式：v主版本号.次版本号.补丁号
v1.0.0
v2.1.3
v1.0.0-beta.1
v2.0.0-rc.2
```

| 版本类型 | 示例 | 说明 |
|---------|------|------|
| 正式版 | v1.0.0 | 稳定发布 |
| 补丁版 | v1.0.1 | 修复 bug |
| 测试版 | v1.1.0-beta.1 | 功能测试中 |
| 候选版 | v2.0.0-rc.1 | 即将正式发布 |

### 2. 版本标题 (Release title)

**必填**，简短描述这个版本的主题，让人一眼看懂。

```bash
# 格式：[项目名] v版本号 - 核心亮点
[项目名] v1.0.0 - 首版发布
[项目名] v1.1.0 - 新增批量扫描功能
[项目名] v2.0.0 - 重大更新：支持多相机
[项目名] v1.0.1 - 修复离线模式崩溃问题
[项目名] v1.2.0-beta.1 - 测试版：AI 识别功能
```

### 3. 内容描述 (Description)

**可选但强烈推荐**，详细说明本次更新内容，支持 Markdown 格式。

## 正式版模板

```markdown
## 🚀 新功能
- 支持批量条码扫描
- 新增离线模式缓存

## ⚡ 性能优化
- 扫描速度提升 30%
- 内存占用降低 20%
- 启动速度提升 50%

## 📦 下载说明
- Windows: Barcode_Cap_Offline_v1.0.0_Setup.exe
- Linux: Barcode_Cap_Offline_v1.0.0.tar.gz

## 测试版/预览版模板

```markdown
## ⚠️ 预发布版本
此版本为测试预览版，请勿用于生产环境！

## 🆕 新增内容
- 新增 AI 条码识别（实验性）
- 新增云端同步功能（测试中）

## 🐛 已知问题
- 批量扫描偶发卡顿（修复中）
- 云端同步数据可能丢失（优化中）

## 🧪 测试重点
请重点测试以下功能并反馈：
1. AI 识别的准确性
2. 云端同步的稳定性
3. 批量扫描的性能

## 📋 反馈渠道
- Issue: https://gitea.xxx.com/xxx/xxx/issues
- 邮件: dev@xxx.com
```

## 补丁版/修复版模板

```markdown
## 🔧 紧急修复

### 修复的问题
- **严重**: 修复数据库连接池耗尽导致服务崩溃 (#123)
- **中等**: 修复扫描结果保存失败 (#124)
- **次要**: 修复界面文字错误 (#125)

### 受影响版本
- v1.0.0 ~ v1.0.5

### 升级建议
**强烈建议**所有 v1.0.x 用户立即升级。

### 回滚方案
如有问题，可通过以下命令回滚：
```bash
git checkout v1.0.0
```
```

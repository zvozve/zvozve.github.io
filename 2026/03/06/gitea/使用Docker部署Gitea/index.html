注意事项

  1. 版本一致：新旧服务器 Gitea 版本号要一致
  2. 权限：Linux 上注意 1000:1000 用户
  3. 数据库切换：更换数据库类型需要额外步骤
  4. 远程 URL：迁移后需要更新所有客户端仓库的远程地址
  5. 定时任务：原服务器上的备份 cron / Task Scheduler 需要重新配置

迁移检查清单

  • 停止源服务器 Gitea 服务
  • 创建完整备份
  • 传输备份到新服务器
  • 新服务器部署相同版本的 Gitea
  • 恢复备份数据
  • 更新配置文件中的域名/IP
  • 启动新服务器服务
  • 测试所有功能正常
  • 更新 DNS 或客户端远程地址
